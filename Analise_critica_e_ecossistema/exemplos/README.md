# Exemplos e simulador offline

Execute `Abrir_simulador.cmd` no Windows ou abra `simulador.html` diretamente
no navegador. O simulador funciona sem Rust, Cargo ou internet.

Os exemplos reais estão nas pastas `json_serde`, `cli_clap` e `concorrencia`.
Cada uma contém apenas o código-fonte e o `Cargo.toml`, sem binários ou pastas
geradas pelo Cargo.
